# Festin cursors

House engraved style (bead festin-3d6.62): ivory fill, dark ink outline, hatched shadow side, light rim. PNG with transparency; `name.png` is 32x32 (1x), `name@2x.png` is 64x64 (2x). Hotspot x,y is in the 32 grid (use it for both sizes).

| cursor | files | hotspot |
|---|---|---|
| default | `default.png`, `default@2x.png` | 3,3 |
| pointer | `pointer.png`, `pointer@2x.png` | 11,2 |
| grab | `grab.png`, `grab@2x.png` | 14,15 |
| grabbing | `grabbing.png`, `grabbing@2x.png` | 15,16 |
| text | `text.png`, `text@2x.png` | 16,16 |
| zoom-in | `zoom-in.png`, `zoom-in@2x.png` | 13,13 |
| zoom-out | `zoom-out.png`, `zoom-out@2x.png` | 13,13 |
| ew-resize | `ew-resize.png`, `ew-resize@2x.png` | 16,16 |
| not-allowed | `not-allowed.png`, `not-allowed@2x.png` | 16,16 |

CSS: `cursor: image-set(url(/art/cursors/NAME.png) 1x, url(/art/cursors/NAME@2x.png) 2x) X Y, NATIVE-KEYWORD;`
