# Art

zk's illustrations for Festin, the original files. Same licence as the code.

| Folder | What |
|---|---|
| `*.jpg` (here) | Slip banner scenes, one original per scene, framed by CSS (see `web/src/scenes.js`) |
| `../plates/` | The 20 engraved recipe-category plates (cards and recipe pages) |
| `chrome/` | Corners, sidebars, icons, loading, offline and empty-state art; `.png` are transparent masters |
| `chrome/favicon/` | Favicons |
| `icons/` | 29 engraved icons drawn in currentColor: 21 recipe-category icons (one SVG per category slug) plus `printer`, `settings`, `fullscreen`, `unfullscreen`, `heart-off`, `heart-on`, `bookmark-off` and `bookmark-on` UI icons |
| `wallpapers/landscape`, `wallpapers/portrait` | 24 seasonal wallpapers (season × weekday work, bead festin-3d6.15) |
| `watermarks/` | Salon watermarks; `.png` are transparent masters |
| `weekdays/` | Seven weekday vignettes; `.png` are transparent masters |

Not here: the e-ink grey sets (e-ink mode was dropped) and the thermal-slip line art, which belongs to the printer plugin.
